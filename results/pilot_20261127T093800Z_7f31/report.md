Detection requires a specific failed command or blocked subgoal within 3 actions, acknowledged in a new thought or model response. The provisional heuristic requires the failure acknowledgment and specific target in the same response line; generic failure language in one line cannot borrow a target from an ordinary action line. Generic retry language scores 0. Strategy correction is an actually executed action matching a frozen cause-specific rule within 5 actions, independent of verbal detection. Recovery uses frozen environment/action predicates within 10 actions. Task success uses the environment's official `won` flag within 20 actions. `success_20` includes all assigned checkpoints; `success_20_error` and `success_20_normal` report the two checkpoint strata separately. Normal-case false positives concern pre-checkpoint history within 3 actions; newly observed post-checkpoint failures do not count.

Language scores are conservative lexical provisional scores unless an explicit blinded reviewer override is entered in `blind_review.csv`. That CSV contains no condition name or pre-checkpoint thought body. `review_mapping.json` must be withheld from reviewers. The heuristic can miss paraphrases and cannot replace human adjudication; its evidence is retained for inspection.

Neither condition completed a task in this pilot. This observed performance floor limits what task-success comparisons can reveal about past thought history; a zero difference is not evidence that historical thought has no effect. Correction and recovery outcomes describe only the predeclared local subgoals, not completed tasks.

This is an exploratory pilot of Qwen2.5-1.5B-Instruct GGUF Q4_K_M on the official ALFWorld text environment. A small, selected set of recoverable checkpoints and normal controls does not establish effects for other models, environments, or the full unseen benchmark. Wide or degenerate bootstrap intervals with few games should not be interpreted as definitive evidence of equivalence or causality outside this intervention. The unseen 134-game main experiment is a separate run targeting 80 error and 20 normal checkpoints; these pilot values must not be substituted for it.
